# SmartDash

Smart Dashboard untuk content creator — TikTok, YouTube, Instagram, WhatsApp.

## Tech Stack
- Next.js (App Router) + TypeScript
- Tailwind CSS

## Struktur Project
- `app/` — halaman & API routes
- `components/` — komponen UI (ui/, layout/, hermes/, dashboard/, content/, creator/, schedule/, analytics/, revenue/, integrations/)
- `lib/` — util & integrasi (supabase/, hermes/, platforms/, ffmpeg/)
- `types/` — definisi tipe data
- `hooks/` — custom React hooks
